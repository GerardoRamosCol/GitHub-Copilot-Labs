# Agentic Course Assets

Copy only the starter web application before Lab 1. The templates are reviewed recovery
snapshots; learners should author and inspect their own customizations first.

| Asset | Learner destination | Used in |
|---|---|---|
| [Starter web application](starter-workspace/README.md) | learner workspace root | Lab 1 onward |
| [Repository instructions](templates/copilot-instructions.md) | `.github/copilot-instructions.md` | Lab 2 onward |
| [Targeted instructions](templates/release-docs.instructions.md) | `.github/instructions/release-docs.instructions.md` | Lab 3 onward |
| [Readiness prompt](templates/release-readiness.prompt.md) | `.github/prompts/release-readiness.prompt.md` | Lab 4 onward |
| [Planner agent](templates/release-planner.agent.md) | `.github/agents/release-planner.agent.md` | Lab 5 onward |
| [Reviewer agent](templates/release-reviewer.agent.md) | `.github/agents/release-reviewer.agent.md` | Lab 5 onward |
| [Readiness skill](templates/release-readiness/SKILL.md) | `.github/skills/release-readiness/` | Lab 6 onward |

Never copy credentials, organization identifiers, or learner-specific values
into course artifacts.
