# Northstar repository instructions

- Treat `docs/release-policy.md`, `docs/change-summary.md`,
  `docs/known-risks.md`, and `release.json` as release evidence.
- Never infer that a missing fact satisfies a release gate.
- Separate verified facts, assumptions, risks, and open questions.
- Cite a workspace-relative source for every readiness conclusion.
- Do not modify source evidence while preparing a report.
- Keep required work local; do not create issues, pull requests, or releases.
- Before completion, inspect `git diff` and report changed files.
