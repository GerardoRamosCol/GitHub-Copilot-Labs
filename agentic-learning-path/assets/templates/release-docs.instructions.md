# Release documentation rules

- Use headings in this order: Decision, Gate assessment, Risks, Open questions.
- Mark each gate `Pass`, `Blocked`, or `Unknown`.
- Include a relative source link beside each factual conclusion.
- Do not convert missing evidence into a pass.
