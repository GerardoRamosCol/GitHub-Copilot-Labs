# Release Policy

A production release is ready only when:

1. every planned change has an owner and verification evidence;
2. no unresolved critical risk exists;
3. high risks have a documented mitigation owner;
4. user-facing changes include release notes;
5. rollback steps have been reviewed; and
6. the release metadata identifies the same version and target date as the
   change summary.

A missing fact is not a passed gate. Readiness reports must label assumptions and
open questions instead of inventing evidence.
