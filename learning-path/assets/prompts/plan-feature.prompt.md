name: "Plan Inventory Feature"
argument-hint: "Provide the goal, acceptance criteria, and allowed scope"
agent: "plan"
---

Inspect the attached selected-track files and repository instructions, then plan
the requested inventory feature.

Return:

1. assumptions and unresolved questions;
2. a phased implementation plan;
3. files and public symbols expected to change;
4. focused tests mapped to each acceptance criterion;
5. focused and full validation commands;
6. operations that require approval; and
7. scope or regression risks.

Use no database, web framework, cloud service, or new dependency unless the
request explicitly requires one. Do not edit files or run commands. Wait for
approval after presenting the plan.
